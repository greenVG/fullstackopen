# Notes App SPA Load Diagram

```mermaid
%% Mermaid syntax starts here
sequenceDiagram
    %% Define participants
    participant Browser
    participant Server

    %% Initial request for the SPA HTML file
    Browser->>Server: GET https://studies.cs.helsinki.fi/exampleapp/spa
    Server-->>Browser: HTML file (spa)

    %% Browser parses HTML and requests CSS and JS assets
    Browser->>Server: GET /main.css
    Server-->>Browser: CSS file

    Browser->>Server: GET /main.js
    Server-->>Browser: JavaScript file

    %% JavaScript is executed by the browser
    Note over Browser: JavaScript runs and executes app logic

    %% JavaScript makes an AJAX request for the notes data
    Browser->>Server: GET /data.json (AJAX)
    Server-->>Browser: JSON data (notes)

    %% Notes are rendered dynamically in the page
    Note over Browser: JS dynamically updates the page with notes
